# Componentes de terceiros

O IdleForge utiliza componentes distribuídos separadamente por seus respectivos autores:

| Componente | Versão | Licença |
|---|---:|---|
| Microsoft.Web.WebView2 | 1.0.4314.35 | Termos de licença incluídos em `licenses/Microsoft.Web.WebView2-LICENSE.txt` |
| Microsoft.Data.Sqlite / Microsoft.Data.Sqlite.Core | 10.0.14 | MIT |
| SQLitePCLRaw | 2.1.13 | Apache-2.0 |
| System.Memory | 4.5.3 | MIT |

O pacote self-contained também inclui componentes do runtime .NET, sujeitos aos avisos e termos da Microsoft aplicáveis ao .NET 8.

Este arquivo documenta dependências de terceiros. O código do IdleForge é disponibilizado separadamente sob a Apache License 2.0, conforme o arquivo `LICENSE`.
