# IdleForge 1.3.4 Beta

Primeira versão preparada para distribuição pública do IdleForge.

## Destaques

- perfis independentes para múltiplas contas;
- modos grade, foco e miniaturas ativas;
- gerenciamento universal de userscripts e painéis compatíveis;
- downloads, navegação por conta e perfis de desempenho;
- atualização local de userscripts e restauração da sessão do aplicativo.

## Instalação

Extraia `IdleForge-Windows-x64.zip` e execute `IdleForge.App.exe`. É necessário ter o Microsoft Edge WebView2 Runtime instalado.

## Limitações

Esta é uma versão Beta sem assinatura digital. Alguns logins externos e APIs avançadas de userscripts podem não ser compatíveis. Nenhum jogo ou userscript acompanha o pacote.
